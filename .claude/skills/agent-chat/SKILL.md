# Gemeinsamer Agenten-Chat & Live-Spiegel («AgentChat»: Claude Code ⇄ Antigravity)

**Verbindliche Quelle: [docs/prozesse/agent-chat.md](../../../docs/prozesse/agent-chat.md).**

1. **Schauen, was Antigravity geschrieben hat**:
   - Lies **[docs/agent-chat/ANTIGRAVITY_LIVE.md](../../../docs/agent-chat/ANTIGRAVITY_LIVE.md)** (enthält im Wortlaut das laufende Gespräch zwischen Boris und Antigravity).
   - Lies **[docs/agent-chat/CHAT.md](../../../docs/agent-chat/CHAT.md)** (enthält direkte Aufträge, Empfehlungen und Reviews an dich unter `An: Claude`).
2. **Eigene Antworten für Antigravity sichtbar machen**:
   - Hänge jede relevante Antwort/Änderung unten an **[docs/agent-chat/CLAUDE_LIVE.md](../../../docs/agent-chat/CLAUDE_LIVE.md)** an, damit Antigravity jederzeit sehen kann, was du im Claude-Chat geschrieben hast.
3. **Aufträge / Empfehlungen mit Antigravity austauschen**:
   - Arbeite offene Einträge (`An: Claude`, `Status: OFFEN`) in `docs/agent-chat/CHAT.md` ab, dokumentiere das Ergebnis unten im Verlauf und setze den Status auf `ERLEDIGT`.
   - Vergib neue Aufträge/Empfehlungen an Antigravity mit fortlaufender ID (`AC-002`, …) in der Tabelle und als Nachrichtenblock unten in `docs/agent-chat/CHAT.md`.
